Data Flow — Request Lifecycle

FilterBar.vue
User picks Time Period, Warehouse, Category, or Order Status
→
useFilters()
Shared reactive filter state (singleton refs) read by every view
→
api.js
Builds query params, fires axios.get() to FastAPI
→
main.py route
apply_filters() / filter_by_month() narrow the in-memory list
→
Pydantic model
Validates & serializes the response shape
→
Vue ref + computed
Raw data stored in a ref; derived totals/charts computed reactively

Key API Endpoints

Method Path Filters Purpose
GET /api/inventory warehouse, category List inventory items on hand
GET /api/orders warehouse, category, status, month List orders, supports quarter or month filtering
GET /api/dashboard/summary warehouse, category, status, month Aggregated KPIs for the Overview page
GET /api/demand · /api/backlog none Demand forecasts and backlog with purchase-order status
GET /api/spending/* none Summary, monthly, category, and transaction-level spend
GET /api/reports/quarterly · /monthly-trends none Aggregates computed on the fly from orders
